The short version

This is a personal journal app. Everything you type — profiles, doses, symptoms, observations, reminders — is stored only in your browser on your device. Saved records live in IndexedDB. An entry you have not saved yet can be held temporarily in the browser's per-tab sessionStorage (so an unfinished form can survive an app update) — it stays in this tab on this device and is gone when the tab closes. The app does not send your records anywhere. There is no account, no server database, and no analytics.

What does leave your device

  • Loading the app: the site is hosted on GitHub Pages. When your browser loads the app shell, GitHub receives your IP address and keeps standard web-server logs, as with any website. The app's operator does not control those logs.
  • Links you choose to open: verification links to official sources (DailyMed, Drugs@FDA, FDA pages). These links include the product name you are checking in their address — the operators of those sites can see that search term. No other personal data is included.
  • Exports and summaries: only when you choose Export or print/download an appointment summary. The file is created in your browser and saved where you choose; the app does not transmit it anywhere. Once a file is downloaded, shared, or moved (for example to a clinician, a chat app, or cloud storage), the app no longer controls it — treat exported health records accordingly.

What never happens

  • The app never uploads, syncs, or shares your records. There is no third-party transmission of user data.
  • The app never attaches data to feedback automatically — there is no such feature.
  • Data leaves the machine only when you explicitly export it. A backup file includes every profile stored on this device, not only the profile currently open — keep it accordingly private.

Who can see your data on this device

Profiles organize records; they are not passwords. Anyone who can use this device and this browser profile can open every profile in the app, including exports and summaries stored on the device. Clearing the browser's site data for this app deletes every record permanently.

Children

This app is intended for adults organizing existing treatment or use records. It is not marketed to minors, and it does not direct appearance-enhancing or growth-related content to children.

Feedback

Feedback and problem reports go to the app's public issue tracker: GitHub Issues on this repository. Issues are public — do not include medical records, symptom details, product names tied to you, export files, or screenshots of your entries. The app never attaches data to feedback automatically — there is no such feature — so anything you share is only what you type yourself.
